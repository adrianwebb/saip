## What is SAIP?

SAIP is a two-service continual-learning platform that closes the loop between AI inference and training:

- **Inference Gateway** serves OpenAI-compatible chat completions via vLLM with dynamic per-request LoRA adapter selection
- **Training Gateway** runs Axolotl fine-tuning jobs using three methods: knowledge embedding, corrective SFT, and weighted KTO

Both services share a Cloudflare R2 object store for adapters, knowledge, sessions, and feedback. They can run on a single 7 GB VRAM GPU or scale to remote GPU nodes.

## Key Features

- **Per-request adapter selection** — callers are mapped to adapters automatically; no client-side LoRA management
- **Three training methods** — knowledge embedding (continued pretraining), corrective SFT (feedback-weighted), weighted KTO (scalar reward magnitudes)
- **Cordis plugin architecture** — both services are composed of focused, hot-reloadable plugins
- **File-based user manifests** — simple YAML mapping of callers to adapter groups
- **CLI-first operations** — `saip awake`, `saip sleep`, `saip down`, `saip status`
- **Remote-ready** — deploy locally or to Hyperstack GPU nodes with the same configuration

## Technology Stack

| Component | Technology |
|-----------|-----------|
| Plugin framework | Cordis v4 |
| Inference engine | vLLM (multi-LoRA, AWQ) |
| Training framework | Axolotl (QLoRA, SFT, KTO) |
| API framework | Hono |
| Base model | Qwen3.5-4B (AWQ) |
| Object storage | Cloudflare R2 |
| Containerization | Docker Compose v2 |
| Language | TypeScript (Node.js ≥ 22) |
